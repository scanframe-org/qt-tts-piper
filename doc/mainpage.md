## Overview

This project implements a text-to-speech plugin using the [Piper1GPL](https://github.com/OHF-Voice/piper1-gpl)
engine for Qt6.  
For the plugin the [QTextToSpeech](https://doc.qt.io/qt-6/qtexttospeech.html) class is derived and implemented.

### Classes

* `::SfTextToSpeechPlugin`
* `::sf::TextToSpeechEngine`
* `::sf::TextToSpeechSynthesizer`
